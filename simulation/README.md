# Mô phỏng demoSlam

- `scenarios/bmap1_demo_fixed_camera.xml` chứa phòng giữa và robot với cụm camera cố định.
- `mujoco/` chứa runner và tích hợp bộ điều khiển RB.
- `demo/` chứa tuyến quét, thu và đồng bộ cảm biến, tích hợp TSDF cùng các bridge hiển thị.

Cách build, chạy và mở bản đồ có trong [README gốc](../README.md).
